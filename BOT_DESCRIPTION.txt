Veritas — AI fact-checking for Discord

Veritas checks claims and answers questions using mainly official institutions and scientific sources (not social media rumors).

Website / panel: https://5spartan9.github.io/Veritas-BotDC/
Dashboard login (when hosted): set PANEL_URL in .env

Quick start:
• /about — what Veritas is
• /help — full command list
• /ask question: your question
• /check text: a claim to verify
• Reply to any message with @Veritas is that true?
• Right-click a message → Apps → Verify claim

Also: /explain, /sources, /compare, /cite, and music via /music.
