Veritas

Truth over noise.

An AI fact-checking bot for Discord — built around official data and scientific sources, not social media rumors.

Add to Discord See commands

Built for claims, not chaos.

Veritas focuses on one job: checking what people say against sources that actually matter.

Official & scientific first

Prioritizes institutions and peer-reviewed research. If evidence is weak, it says unverified instead of guessing.

Reply to check

Reply to any message with @Veritas is that true? — no need to repeat the claim.

Clear verdicts

Structured answers with confidence, uncertainty, and source links — readable embeds, not walls of text.

Multilingual

Auto-matches the user’s language, or lock a server to English, Polish, Russian, or Chinese.

Commands that matter.

Start with these. Full list lives in /help and /about.

/check Fact-check a statement
/ask Ask from reliable sources
/debate Fact / opinion / unproven
/multicheck Verify several claims at once
/explain Simple explanation + sources
/sources Credible sources for a topic
@Veritas Chat reply / verify by mention
/music Optional playback controls
